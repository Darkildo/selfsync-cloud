# Selfsync Cloud

Плагин Obsidian для Selfsync Cloud — облачной версии [selfsync](https://github.com/Darkildo/selfsync). Синхронизирует vault без потерянных правок: автоматическое слияние, копии при конфликтах, восстановление удалённых файлов и история. Сквозное шифрование включено всегда.

> **Состояние:** в разработке. Сервис ещё не открыт, плагина нет в каталоге Obsidian.

Если хотите свой сервер, берите открытый плагин [selfsync](https://github.com/Darkildo/selfsync): ему аккаунт не нужен.

## Что важно знать

- **Нужен аккаунт.** Регистрация по email и паролю прямо в плагине.
- **Платные тарифы.** Есть бесплатный тариф, более крупные будут платными. Тарифы, которые ещё не доступны, показаны серыми.
- **Сеть.** Плагин обращается только к серверам Selfsync Cloud в регионе, выбранном при регистрации: СНГ или Europe. Заметки, имена файлов и папок шифруются на устройстве до отправки, сервис их прочитать не может.
- **Без телеметрии.** Плагин не собирает аналитику. Сервер хранит то, что нужно синхронизации: email аккаунта, имена устройств, размеры и время изменения зашифрованных данных.
- **Потеря пароля и фразы восстановления — потеря данных.** У сервиса нет ключа к заметкам, поддержка не сможет вернуть доступ.

## Исходники и аудит

Движок синхронизации не скопирован сюда: это открытый selfsync, подключённый подмодулем `core/` на выпущенном теге. CI не соберёт плагин ни из чего другого. Этот репозиторий добавляет только облачные экраны: регистрацию и вход, тарифы и приглашения устройств.

Как проверить релиз: сверьте коммит `core/` с одноимённым тегом selfsync и соберите:

```sh
git clone --recurse-submodules https://github.com/Darkildo/selfsync-cloud
cd selfsync-cloud
core/scripts/build-wasm.sh   # нужны Rust (версия из core/rust-toolchain.toml), wasm-bindgen-cli, binaryen
npm ci && npm run build      # main.js
npm test
```

Сквозной тест идёт против сервера Selfsync Cloud, если `SELFSYNC_CLOUD_BIN` указывает на его бинарь; без него тест пропускается. Тест проверяет, что ни в одном запросе к серверу нет открытого текста заметок и имён файлов.
