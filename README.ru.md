# Selfsync Cloud

Плагин Obsidian для Selfsync Cloud — облачной версии [selfsync](https://github.com/Darkildo/selfsync). Синхронизирует vault без потерянных правок: автоматическое слияние, копии при конфликтах, восстановление удалённых файлов и история. Сквозное шифрование включено всегда.

> **Состояние:** ранний выпуск. Плагин опубликован в GitHub Releases, в каталоге Obsidian его пока нет. Все аккаунты на бесплатном тарифе.

Если хотите свой сервер, берите открытый плагин [selfsync](https://github.com/Darkildo/selfsync): ему аккаунт не нужен.

## Установка

1. Скачайте `main.js`, `manifest.json` и `styles.css` из [последнего релиза](https://github.com/Darkildo/selfsync-cloud/releases/latest).
2. Положите их в `<ваш vault>/.obsidian/plugins/selfsync-cloud/`.
3. В Obsidian откройте *Настройки → Сторонние плагины*, при необходимости выключите безопасный режим и включите **Selfsync Cloud**.

Работает на компьютере и телефоне, нужен Obsidian 1.13 или новее. Не включайте его вместе с открытым плагином selfsync в одном vault'е.

## Как пользоваться

**Первое устройство.** Откройте *Настройки → Selfsync Cloud*, нажмите **Начать синхронизацию** и выберите регион (СНГ или Europe) — там будут храниться зашифрованные данные. Ни email, ни пароль не нужны: аккаунт создаётся сразу, vault шифруется и отправляется. В настройках появится **фраза восстановления** из 24 слов — запишите её в ближайшее время: это единственный способ войти в аккаунт, если устройства потеряны. Пока она не отмечена записанной, плагин напоминает в строке состояния.

**Ещё устройства.** На подключённом устройстве нажмите **Подключить устройство** и отсканируйте QR-код камерой нового: откроется Obsidian, устройство войдёт в аккаунт и подключится к тому же vault'у. Без камеры введите код под QR в **Уже есть аккаунт → Ввести код**, а затем фразу восстановления (или пароль, если вы его добавили). Коды одноразовые и действуют 10 минут. Можно войти и одной фразой, без других устройств.

**Email и пароль** — по желанию, в настройках аккаунта: с ними можно входить вводом на любом устройстве и подтверждать паролем удаление. Один пароль для аккаунта и шифрования, он не покидает устройство.

**Каждый день.** Синхронизация идёт сама. Одновременные правки сливаются или остаются копиями при конфликте; удалённые файлы и прежние версии — в истории и корзине, как в selfsync. В настройках видно занятое место, входы в аккаунт и устройства (любое можно отключить) и тарифы; там же выход и удаление аккаунта со всеми данными.

## Что важно знать

- **Нужен аккаунт.** Он создаётся одним нажатием прямо в плагине, без email и пароля; их можно добавить потом. Нажимая «Начать», вы принимаете условия оферты.
- **Платные тарифы.** Есть бесплатный тариф, более крупные будут платными. Тарифы, которые ещё не доступны, показаны серыми.
- **Сеть.** Плагин обращается только к серверам Selfsync Cloud в регионе, выбранном при создании аккаунта: СНГ или Europe. Заметки, имена файлов и папок шифруются на устройстве до отправки, сервис их прочитать не может.
- **Без телеметрии.** Плагин не собирает аналитику. Сервер хранит то, что нужно синхронизации: имена устройств и входов, email (если добавлен), размеры и время изменения зашифрованных данных.
- **Что хранится на устройстве.** Ключ аккаунта и, до отметки «записал», слова фразы восстановления лежат в локальном хранилище Obsidian этого устройства (не в папке vault'а). QR-код подключения несёт ключ аккаунта: показывайте его только своему устройству.
- **Файлы мимо API vault'а.** На компьютере движок синхронизации использует модуль `fs` из Node — только внутри папки vault'а и папки самого плагина: чтобы заменять файлы атомарно (сбой не оставит наполовину записанную заметку) и читать большие файлы частями. На телефоне — только API vault'а Obsidian.
- **Буфер обмена.** Плагин пишет в буфер обмена только по кнопкам копирования (фраза восстановления, код подключения, журнал синхронизации) и никогда его не читает.
- **Потеря всех устройств без записанной фразы — потеря данных.** У сервиса нет ключа к заметкам, поддержка не сможет вернуть доступ. Заметки на устройствах при этом остаются.

## Исходники и аудит

Этот репозиторий добавляет только облачные экраны: создание аккаунта и вход, фразу восстановления, тарифы и подключение устройств. Движок синхронизации — открытый selfsync на выпущенном теге, он лежит в `core/`: исходники и стили его плагина, лицензия MIT и движок, собранный в WebAssembly. Тег и коммит записаны в `core/SOURCE`. CI заново собирает `core/` из этого тега командой `scripts/core.sh check` и падает, если результат не совпадает побайтно, — так `core/` не может разойтись с опубликованным selfsync.

Для сборки плагина нужен только Node:

```sh
git clone https://github.com/Darkildo/selfsync-cloud
cd selfsync-cloud
npm ci && npm run build      # main.js, styles.css
npm test
```

Проверить `core/` самостоятельно (нужны Rust, `wasm-bindgen-cli` и `wasm-opt` версий, которые назовёт скрипт):

```sh
scripts/core.sh check
```

Файлы релиза собираются в GitHub Actions и несут аттестацию происхождения: `gh attestation verify main.js -R Darkildo/selfsync-cloud`.

Сквозной тест идёт против сервера Selfsync Cloud, если `SELFSYNC_CLOUD_BIN` указывает на его бинарь; без него тест пропускается. Тест проверяет, что ни в одном запросе к серверу нет открытого текста заметок и имён файлов.
